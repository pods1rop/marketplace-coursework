# MARKETPLACE — прототип маркетплейса товаров

Курсовой проект по дисциплине «Распределённые программные системы» (ВлГУ, гр. ПРИ-123, Голенкевич Д.А.).
Площадка для продажи новых и second-hand/винтажных товаров с ролями покупателя, продавца, модератора и администратора.

Пояснительная записка: [`docs/report`](docs/report) (DOCX и PDF), диаграммы PlantUML: [`docs/diagrams`](docs/diagrams).

## Возможности

- **Гость** — главная с новинками и популярными товарами, каталог с AJAX-фильтрами (категория, пол, состояние, цвет, размер, цена), поиск, страница товара, бренды, регистрация и вход.
- **Покупатель** — корзина, оформление заказа, история заказов и отмена нового заказа, избранное, отзывы с оценкой 1–5, профиль с аватаром, уведомления, заявка на роль продавца.
- **Продавец** — добавление товаров с несколькими фото, редактирование, снятие с продажи и возобновление, повторная подача отклонённого товара, заказы покупателей и смена их статуса.
- **Модератор** — очередь модерации, одобрение и отклонение с причиной, блокировка пользователей и предупреждения.
- **Администратор** — дашборд со статистикой, заявки продавцов, управление ролями, статистический отчёт в CSV.

## Технологии

Java 17, Spring Boot 3.2 (Web MVC, Data JPA, Security, Validation, Cache), Thymeleaf, Tailwind CSS, MySQL 8, JUnit 5 + Mockito, Apache JMeter.

## Запуск

1. Установить JDK 17+, Maven и MySQL 8.
2. Создать `marketplace/src/main/resources/credentials.properties` по образцу `credentials.properties.example`
   (логин и пароль MySQL). База `marketplacedb` создаётся автоматически.
3. Запустить:

   ```
   cd marketplace
   mvn spring-boot:run
   ```

4. Открыть http://localhost:8080.

При первом запуске создаются категории, бренды, демонстрационные товары и учётные записи:

| Роль          | Логин         | Пароль        |
|---------------|---------------|---------------|
| Администратор | `admin`       | `admin123`    |
| Продавец      | `demo_seller` | `password123` |

Покупателя можно зарегистрировать на странице входа; модератора назначает администратор.
